# Projektregel

Bei jedem Release `CHANGELOG.md` um einen Eintrag für die neue Version ergänzen. Beschreibe die tatsächlich umgesetzten, für Nutzer relevanten Änderungen anhand der geprüften Änderungen; keine unbestätigten Behauptungen aufnehmen. Den Eintrag vor der Veröffentlichung zusammen mit dem Release prüfen.
